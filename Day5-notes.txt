## How to create k8s workloads
--------------------------------------


Kubernetes has a REST API for all the resources of kubernetes exposed by kube API Server

All the resources that can be created by k8s can be fetched by `kubectl api-resources` command

Play with pods
----------------------------------
Imperative:
---------------------

declarative
-------------------
````yaml````
apiVersion: v1
kind: Pod
metadata:
  name: web3
spec:
  containers:
  - name: nginx
    image: nginx:1.14.2
    ports:
    - containerPort: 80

kubectl apply -f web3.yaml
