## Resources in Kubernetes

Refer - https://kubernetes.io/docs/concepts/configuration/manage-resources-containers/



Requests(min/soft) and limits(max/hard)

Requests - min memory-128MiB/M/Mi   CPU- 0.5---> soft limits

1 VCPU --> 1000m cpu---> 500m(half cpu)---> 0.5 cpu---> 100m(1/10th of the cpu)

2 VCPU ---> 2000m cpu


limits :--> Hard limits

limits: max memory-512Mi CPU: 1

Resources types:
---------------
CPU
Memory
Huge pages --> more memory u need to provide to the Pod



If the resources limits are already set and if the running Pod needs more and more memory , then the pod might get failed and u will get POD status OMMKIllED

POD need more and more CPU then the resources limits, in that case POD will not be failed, but POD will go to threshold where the response/latency will be too high 


A Pod with resources limits has an impact on QOS (Quality of Service)


Refer - https://kubernetes.io/docs/tasks/configure-pod-container/quality-service-pod/
