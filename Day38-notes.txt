Introduction to Ingress controller:
------------------------------------------
1. Ingress controller implements Layer7 LoadBalancing ( HTTP/HTTPS or Applications) in k8s cluster to access the application from outside

2. Service type: LoadBalancer ---> Provided layer 4 as per OSI Reference model

3. LoadBalancer types: Software , Hardware and Cloud

4. Layer 7 LB - Nginx Ingress controller - features:
   1. host based routing - www.rajeshdevops.com
                           movies.rajeshdevops.com #FQDN
						   songs.rajeshdevops.com
						   contactus.rajeshdevops.com
						   home.rajeshdevops.com
   2. Path Based routing:
                    www.rajeshdevops.com/login(URI)
					www.rajeshdevops.com/payment (URI)
					
   3. TLS/SSL Termination
         http-> https
		 https -> certificate
		 
5. Ingress controller is deployed on kubernetes cluster of different platform like on-premises , or cloud 

6. Ingress controller is an application that runs on the cluster to implement http loadbalancing

7. On premises setup, we use Nginx Ingress controller which is the choice as per suggestion made by kubernetes in order to get the stability and further development

8. Other 3rd party controller can be used:
1. HA Proxy Ingress
2. Traefik
3. kong
4. Istio Ingress

refer to the document - https://kubernetes.io/docs/concepts/services-networking/ingress-controllers/
https://kubernetes.io/docs/concepts/services-networking/ingress/

Kuberners Cluster :
---------------------
1. Nginx Ingress Controller -> we need to deploy  , Manifest, Helm
     deployment ---> Replicaset ---> Pod --> 1 Pod - Nginx ingress controller

To implement the ingress resources in on-premises kubernetes cluster, we need to deploy the Nginx Ingres controller

Kubernetes --> has the ingress object or resources, we need to have the ingress resource where we are deriving the ingress rules.
yaml file for implementing the ingress resources

2. Nginx Ingress controller supports default protocols like HTTP,TCP, UDP, WebSocket, grpcRoute

3. Nginx ingress controller also supports VirtualServer and VirtualServerRoute feature as well 

Nginx  ---> configuration , Virtual sites 

4. After Nginx Ingress controller is installed , it comes up with 2 components:
  1. IC process --> main process, configures the Nginx for ingress and other resources created in the cluster
  2. Nginx Master process --> which controls the nginx worker process
  3. Nginx work processes --> which handles the client traffic and Load Balance the traffic to the backend applications.
