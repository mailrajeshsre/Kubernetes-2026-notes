Volumes:
-----------------------------------------
1. In general, Containers are ephemeral which files will be lost once the container crashes

2. Kubelet restarts the containers which comes with clean data will be lost

3. When we want to share the data across the container inside the pod , we can use volumes.

4. When containers restarts with clean data, POD volume will help to persist the data , since POD uses volumes as Persistent storage solution for containers

5. Container mounts the directory under .spec.containers.volumeMounts to volumes under .spec.volumes( create the volume) with common name

6. Kubernetes supports 2 types of Volumes:
    1. Ephemeral Volume (emptyDir, configMap, Secret, Downwards API , CSO ephemeral volumes, etc )
	2. P	eristent Volume ( PV --> Static and Dynamic PV with storageclass)
