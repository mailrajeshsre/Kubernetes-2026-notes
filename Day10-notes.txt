Introduction to POD
-----------------------

POD is smallest deployable unit in kubernetes.

Each Pod will be provided with the resources like IP-address , storage and Network 

Whenever the user want to run the microservice/application in the k8s cluster, so basically there is kubernetes resource by the name POD , using the POD resource the kubernetes(API Server) will create a new POD.
