Basic Architecture:
-----------------------------------------------

Kubernetes is a cluster , which is collection of one more more nodes.

Kubernetes cluster have two types of nodes
1. Master Nodes --> manage the cluster
2. Nodes (worker nodes) ---> Run the workloads ( apps)

Kubernetes Master node components
--------------------------------------
1. Kube-API server ( API server)
2. Kube-Scheduler
3. Kube controller-manager
4. etcd


Kubernetes Node Components
--------------------------------------
1. Kubelet
2. Container Runtime 
3. Kube-proxy
