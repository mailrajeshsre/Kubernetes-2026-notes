Accessing the Pod outside the cluster using hostPort:
------------------------------------------

Normally a Pod in kubernetes can be accessed only inside the cluster

To Access it from outside the cluster, we can use hostPort

hostPort binds a node machine port to a container port



docker container run --name web1 nginx

docker container run --name web1 -p 8080:80 nginx
