## YAML format (k8s, Ansible,)
--------------------------------

Introduction YAML structure:
---------------------------------------

YAML: This is a file format for representing data which uses name value or key value pairs as a basic structure.

YAML Files generally have an extension of .yaml or .yml


Basic structure
-----------------

name: <value>

name-1: <value1>
name-2: <value2>
..
...
name-n: <valuen>

Types of data's
----------------------

Simple/Scalar:
---------------
     1. Text
	 2. number
	 3. boolean

Complex:
---------
     1. object/map
	 2. array/list
	 
1. Text data type:
---------------------
city: Bangalore
city: 'Bangalore'
city: "Bangalore"

2. number
-------------------------
population: 12.7
age: 35

3.boolean data type
--------------------------------------
metro: true/false
metro: yes/no

4. list or array
----------------------------

areas: ['Rajajinagar', 'Vijaynagar', 'Nagarbhavi']

areas:
- Rajajinagar
- Vijaynagar
- Nagarbhavi

areas:
  - Rajajinagar
  - Vijaynagar
  - Nagarbhavi
  
5. Object/map
--------------------------
yaml
-----------------
address:
  flatno: 601
  building: nilgiri
  area: Health layout
  city: Bangalore
